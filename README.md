# Amautozap — интеллектуальный консультант автозапчастей

Чат-бот на базе Qwen 3.5 для интернет-магазина автозапчастей.

## Функции
- Подбор запчастей по параметрам автомобиля
- Диагностика по описанию симптомов
- Поиск аналогов по артикулу
- Эскалация оператору (email-уведомления)

## Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Создать файл `.env` с API-ключом (см. ниже)
4. Запустить: `python diplom.py`

## Переменные окружения (.env)
OPENROUTER_API_KEY=ваш_ключ
EMAIL_SENDER=ваша_почта@gmail.com
EMAIL_PASSWORD=пароль_приложения
EMAIL_RECEIVER=почта_получателя@gmail.com

## Примечание
Файлы баз знаний должны лежать в папке `kb/`.
